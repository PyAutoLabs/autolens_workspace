The `guides/plot/advanced` folder contains scripts which show how to use **PyAutoLens** built-in
visualization tools.

The API provides a simple interface with matplotlib for making plots that does not require the user to
write any matplotlib code themselves.

New users should begin with `guides/plot/start_here.py`.

# Files

- `plotters_pixelization`: Plots for pixelized source inversions.
- `plotters_double_source_plane_lens`: Plots for double source-plane lens (DSPL) models.
