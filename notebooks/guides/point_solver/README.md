The `guides/point_solver` folder contains guides on finding the multiple images of a point source and fitting their
positions.

These scripts are intended to help users understand how **PyAutoLens** works.

# Files

- `pairing`: How observed and model images are paired in a position fit, and what happens when the model predicts too many or too few images.
- `limitations`: Every known limit and assumption of `PointSolver`, with how to check each one against an independent oracle.
